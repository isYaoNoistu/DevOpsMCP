# Agent notes

This repository is **read-only ops MCP**, not an application codebase.

1. Read `.cursor/skills/<product>/SKILL.md` before calling that product's tools.
2. Follow `.cursor/rules/devops-mcp.mdc` and `.cursor/rules/no-secrets.mdc`.
3. Never put tokens, passwords, or real hostnames into the repo or into chat.
4. Do not claim you triggered a Jenkins build, muted a Nightingale alert, or changed PostgreSQL data. These binaries have no write tools.
