# Kafka MCP V1 implementation

User approved V1 after live Nightingale inventory. Work only in DevOpsMCP;
do not migrate to cicd or alter live MCP configuration / Kafka resources.

## Design and acceptance

- Go stdio MCP, franz-go client, independent kafka-mcp-server module.
- Local reloadable targets with bootstrap servers, TLS/SASL, stable name,
  topic/group allowlists and explicit message-payload permission.
- Eight read-only tools: list_targets, get_target_info, kafka_capabilities,
  kafka_configs_query, kafka_topic_inspect, kafka_group_inspect,
  kafka_offsets_query, kafka_records_peek.
- Facts carry target, sample time, scope, truncation and classified errors.
- Config values include sources/synonyms; sensitive values stay hidden.
- Consumer group detail preserves member/partition mapping and committed
  offsets, without pretending to expose application position or code stacks.
- Offset queries distinguish earliest, high watermark and last stable offset;
  timestamps use Unix milliseconds. Explicit topic + partition, no broad scan.
- Peek uses manual assignment, no group membership, no commits and no automatic
  topic creation. Default hides key/headers/value. Bounded records, bytes and
  time. Payload requires local target authorization and explicit request.
- No producer/admin writes, transactions, migration or ACL modification tools.

## Tasks

1. Target registry and credentials: tests first, safe public view and reload.
2. Kafka read backend: real protocol queries, precise limits and error handling.
3. MCP schemas and main: validation before dialing, allowlist gates, tests.
4. Docs/examples/skill and build entry: isolated development artifacts outside
   repositories, preserve existing tools and packaging.
5. Run tests/vet, build, stdio smoke, fixture integration (real disposable Kafka
   when runtime is available), independent review and fix findings.

No commits requested. No production Kafka write validation. Report mock,
protocol-fixture and live validation separately.

## Completion (2026-09-18)

All five tasks implemented in DevOpsMCP. Final `go test ./... -count=1`
and `go vet ./...` passed. Windows standalone binary rebuilt outside the
repository; stdio smoke passed initialize, eight read-only tools and local
target listing. Seven broker tests include kfake protocol checks and aborted
versus committed transaction visibility. Independent review findings were
fixed and reviewed again without remaining important blockers.

Docker daemon was unavailable. No real Kafka cluster, production credentials,
TLS/SASL or broker ACL acceptance was performed. No migration to cicd or active
MCP configuration changes were made.
